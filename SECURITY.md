# Security Policy

## Supported Versions

We currently support the latest version on the default branch.

## Reporting a Vulnerability

Please **do not** open public issues for security vulnerabilities.

Instead, report privately by emailing the maintainer at:

- security@users.noreply.github.com

Include as much detail as possible:
- Affected component/file
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

We will acknowledge receipt within 72 hours and provide status updates as the issue is triaged and remediated.

## Disclosure Policy

After a fix is available, we may coordinate a responsible disclosure timeline.
